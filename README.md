# ExcelConsult Research & Technology

**Turning Knowledge Into Solutions.**

Official website source for ExcelConsult, a research, academic mentoring and technology consulting business.

## Run locally
The website is a dependency-free static application:
- Open `index.html` in a browser, or serve it with any local web server.
- Deploy on Netlify: publish directory `.`, no build command.
- Deploy on GitHub Pages: select the `main` branch and root directory.

## Before launching
Edit `index.html` and update `BUSINESS.whatsapp`, `BUSINESS.email`, and `BUSINESS.bookingUrl` with verified contacts. Enquiries open WhatsApp or email rather than being silently lost.

Features: mobile navigation, services, packages, flexible payment calculator, enquiry form, how-it-works workflow, frequently asked questions, and academic integrity policies.

**Important:** Turnitin reports are subject to licensed, authorised access. AI-writing indicators are not conclusive evidence of misconduct. There is no real checkout, payment processing, client login, or backend storage in this initial release.

The business should have a verified legal name, a privacy notice, and properly reviewed service terms before production use.
